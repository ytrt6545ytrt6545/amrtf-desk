【第一次使用：極簡 3 步驟安裝】
1. 下載並解壓縮：
   將下載的 ZIP 檔案解壓縮至電腦任意慣用目錄（例如 D:\AMRTF-Desk 或桌面）。
2. 建立桌面捷徑：
   打開解壓縮資料夾，雙擊執行「建立桌面捷徑.bat」。
   Windows 桌面上會自動生成「大慈恩研討播控艙」專屬曜金圖示捷徑！
3. 日常開箱使用：
   以後每次研討，直接雙擊桌面上的「大慈恩研討播控艙」圖示即可一鍵啟動。

※ 如果您以前安裝過舊版，直接解壓縮新版覆蓋，或在新目錄雙擊「建立桌面捷徑.bat」，
   系統會自動將桌面捷徑導向最新版本，設定無縫繼承！

------------------------------------------------------------

【如何解除安裝？（100% 綠色零殘留）】
1. 刪除桌面捷徑：在桌面上對「大慈恩研討播控艙」捷徑按右鍵選擇「刪除」。
2. 刪除資料夾：直接刪除當初解壓縮的「AMRTF-Desk」整個資料夾即可。
3. 本軟體不寫入 Windows 登錄檔，100% 綠色免安裝，不留任何系統垃圾。

【雙螢幕與現場開箱操作】
1. 接上投影機或外接大螢幕，按下鍵盤「Win + P」切換為「延伸 (Extend)」。
2. 在桌面上雙擊「大慈恩研討播控艙」圖示。
3. 系統會自動拉起兩個視窗：
   - 🖥️【大慈恩放映艙】：自動分配至投影機大螢幕，預設為「曜石護眼深色手抄稿」（可按 F11 全螢幕）。
   - 🎛️【講師主控操作艙】：留在筆電螢幕，採用奢華黑金廣播級 4 大卡片，供主持人從容點擊操作。

【廣播級四大卡片核心功能導覽】

一、講次導航卡片：
1. ◀ 上一講 / 下一講 ▶：一鍵秒切前後講次。
2. 第 0567 講：琥珀金立體發光徽章，當前研討進度一目了然。
3. # 0567 ↻：點擊直接輸入講次號碼秒跳，或重新整理當前講次。

二、走帶播控與進度控制卡片：
1. 音訊進度條滑動拖曳 (Scrubbing)：頂部進度條直接按住左右滑動，微秒級精準尋軌跳轉。
2. 走帶 5 核心鍵：[-10] ➔ [-5] ➔ [中央金色 3D 播放鍵] ➔ [+5] ➔ [+10]。同修沒聽清時，按 -5 或 -10 秒即可俐落倒帶。
3. 從頭：停止音訊並精準歸零回起點。
4. 1.0x / 1.25x / 1.5x：三段倍速隨切。
5. 懸停音量滑桿：滑鼠懸停即可調出音量條，單手滾輪或滑桿調節放映端音量，支援一鍵靜音。

三、手抄稿起訖區間研討卡片：
1. 起點／訖點下拉選單：智能防呆，精準選定研討範圍。
2. 起訖區間循環：精準播至訖點前 0.25 秒微靜音處自動煞停定格並折返重播，研討深入必備！
3. ▶ 播放/暫停：就地播放或定格暫停，畫面紋絲不動。
4. 釋放循環：研討完畢時一鍵釋放區間鎖定，恢復全篇自由推進。

四、延伸螢幕與法會專題影音卡片：
1. A- 至 A+ 原生平滑字級拉桿：10px ~ 22px 範圍無級縮放放映端文字。
2. 播稿：切換大慈恩官方播稿跟進模式。
3. 手抄稿滾動模式三聯鍵：
   -「手動」：完全由主持人手動翻閱，音檔播放時不干擾視線。
   -「持續」：播放時手抄稿自動跟進平滑自然滾動。
   -「區段」：當播到畫面底部時，在一次性推到畫面上半部，減少眼睛追蹤移動文字的疲勞。
4. 全螢幕：一鍵將放映端切換為全螢幕。
5. 法會影音秒播與獨立急煞：前行、密集嘛、迴向一鍵 1080p 秒播，點擊「🛑 停止影片」隨時急煞退出無縫退回手抄稿。
