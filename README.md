## 🌟 為什麼需要 AMRTF-Desk？

過去在研討班主持廣論、廣海明月手抄稿研討時，主持人與幹部往往面臨諸多痛點：
* ❌ **切換手忙腳亂**：在大螢幕上翻找講次、拉動拉桿，台下學員看著滑鼠游標在投影幕晃動，破壞現場莊嚴氣氛。
* ❌ **現場 Wi-Fi AP 隔離**：教室網路常禁止設備互聯，手機常常連不上筆電，無法走動導播。
* ❌ **播稿滾動難以掌控**：字體放大了卻容易擋住、字級按了反而縮回最小、手動滾輪一滾又跑過頭。
* ❌ **剛才一句沒聽清**：想倒帶卻只能粗暴倒退或手動拉進度條，常常把上一句話腰斬，聽不清楚。
* ❌ **引文與前行影片繁瑣**：切換前行、密集嘛、迴向影片時，YouTube 介面跳出紅條、廣告或相關推薦影片，干擾研討沈浸感。

**AMRTF-Desk（大慈恩研討智能導播系統）** 徹底解決了這一切！

## 📦 第一次安裝與使用（30 秒極簡 3 步驟）

本系統為 **100% 綠色免安裝軟體**，無須複雜驅動、不改動系統登錄檔：

```mermaid
graph LR
    A["1. 下載並解壓縮 ZIP"] --> B["2. 雙擊『建立桌面捷徑.bat』"]
    B --> C["3. 雙擊桌面圖示開箱使用！"]
```

### 步驟 1：下載並解壓縮
* 前往 GitHub **[Releases](https://github.com/ytrt6545ytrt6545/amrtf-desk/releases)** 下載最新版綠色便攜壓縮包（例如 `AMRTF-Desk-v1.2.0-Portable.zip`）。
* 解壓縮至電腦任意慣用目錄（建議解壓縮至 `D:\AMRTF-Desk` 或桌面，路徑盡量避免特殊符號）。

### 步驟 2：一鍵建立桌面捷徑
* 打開解壓縮後的資料夾，找到並雙擊執行：**`建立桌面捷徑.bat`**。
* 系統將自動抓取當前資料夾的真實絕對路徑，在 Windows 桌面上自動產生**「大慈恩研討播控艙」**正式專屬曜金圖示捷徑。

### 步驟 3：開箱日常使用
* 日後每次研討時，直接在桌面雙擊**「大慈恩研討播控艙」**圖示即可一鍵啟動！
* 系統將自動拉起兩個視窗：
  1. 🖥️ **現場放映艙**：自動獨佔第二螢幕/投影機，台下學員看見的是純淨的大字護眼手抄稿與影片。
  2. 🎛️ **講師主控操作艙**：留在筆電螢幕，供主持人從容點擊操作。

> 💡 **如果您已經安裝過舊版？**  
> 完全可以再次執行！新版直接解壓縮覆蓋原資料夾，或解壓至新目錄後雙擊 `建立桌面捷徑.bat`，系統會自動將桌面捷徑導向最新版本，舊設定完全相容。

## 🗑️ 如何解除安裝？（100% 綠色零殘留）

因為 AMRTF-Desk 是標準的綠色免安裝設計：
1. **刪除捷徑**：在 Windows 桌面上，對「大慈恩研討播控艙」圖示按右鍵 ➔ **刪除**。
2. **刪除資料夾**：直接將當初解壓縮的「AMRTF-Desk」整個資料夾刪除進資源回收筒。
3. **完成！** 電腦完全恢復原狀，乾淨無比、絕不殘留任何系統垃圾。

## 📸 介面與功能導覽 (v1.2.0 廣播級四大核心卡片)

### 1. 🎛️ 講師主控操作艙（講桌／導播席）
全系統統一採用**奢華曜石黑金深色主題**，低眩光、0 贅字、純實體按鍵與發光指示燈，各研討教室長時間研討眼睛不乾澀：
![主控台操作艙](docs/images/desk-overview.png)

#### 模組 1：講次導航卡片
* **`[◀ 上一講]` / `[下一講 ▶]`**：快速跳轉前後講次。
* **`[第 0567 講]`**：立體琥珀金發光徽章，當前講次清晰可見。
* **`[# 0567 ↻]`**：點擊可直接輸入任意講次數字（如 `3` 或 `504`），秒級跳轉，亦具備一鍵重新載入功能。

#### 模組 2：走帶播控與進度控制卡片
* **🎵 音訊進度條滑動拖曳尋軌 (Scrubbing)**：頂部進度條即時按住左右滑動，微秒級精準跳轉放映端，兩端時間碼即時聯動。
* **走帶 5 核心按鍵矩陣**：
  - **`[-10]` / `[-5]`**：同修聽不清楚時，一鍵精準倒帶 5 秒或 10 秒，字句完好不腰斬。
  - **`[中央金色 3D 播放鍵]`**：純向量播放/暫停巨鍵，立體流體反饋。
  - **`[+5]` / `[+10]`**：快進 5 秒或 10 秒。
* **`[從頭]` 急煞歸零**：一鍵停止音訊並精準歸零回起點。
* **三段倍速切換**：`1.0x` / `1.25x` / `1.5x` 即時切換。
* **🔊 方案 A 懸停音量控制**：滑鼠懸停即可調出音量滑桿，支援單手滾輪或拖動微調放映端輸出音量，亦可一鍵靜音。

#### 模組 3：手抄稿起訖區間研討卡片
* **起點／訖點下拉選單**：收斂整篇手抄稿為 20+ 個黃金段落，智能防呆（訖點絕不早於起點）。
* **`[起訖區間循環]`**：精準播至訖點前 0.25 秒微靜音處自動煞停並折返重播，研討深入必備！
* **`[▶ 播放/暫停]`**：就地播放或定格暫停，畫面紋絲不動。
* **`[釋放循環]`**：研討告一段落時，一鍵解除區間鎖定，恢復全篇自由推進。

#### 模組 4：延伸螢幕與法會專題影音卡片
* **A- 至 A+ 原生平滑字級拉桿**：在 10px ~ 22px 範圍內無級縮放放映端文字大小，精準呈現官方排版。
* **`[播稿]` 開關**：切換大慈恩官方播稿跟進模式。
* **手抄稿滾動模式三聯鍵**：
  - **`手動`**：完全由主持人手動翻閱，音檔播放時不強行位移，同修可安心細看上下文。
  - **`持續`**：音檔播放時手抄稿自動跟進、逐字自然平滑滾動。
  - **`區段`**：當播到畫面底部時，在一次性推到畫面上半部，減少眼睛追蹤移動文字的疲勞。
* **`[全螢幕]` 切換**：放映端一鍵進入或退出全螢幕。
* **法會專題影音秒播與獨立急煞**：
  - **`🎬 前行`**：三稱本師聖號、開經偈、大乘皈依發心（1080p 秒播）。
  - **`🎬 密集嘛`**：宗喀巴大師祈請文經典版官方 MV。
  - **`🎬 迴向`**：真如老師恭誦大迴向。
  - **`🛑 停止影片`**：影片播放中隨時點擊，立即急煞中斷影片並無縫退回手抄稿。

## 🎯 現場雙螢幕操作指引 (Dual-Screen Setup)

在教室進行研討時，強烈建議搭配投影機或外接大螢幕：

1. **接上投影機或外接電視牆**：將 HDMI 線接上筆電。
2. **切換為延伸螢幕模式**：
   - 按下鍵盤快捷鍵：**`Win + P`**
   - 選擇 **「延伸 (Extend)」**。
3. **分配視窗**：
   - **放映端視窗**：拖曳至外接投影幕，按下右上角「全螢幕」或按 `F11` 進入全螢幕放映。
   - **主控台視窗**：保留在筆電螢幕，供主持人從容點擊操作。

## ❓ 常見問題排解 (FAQ)

#### Q1：手機掃碼需要跟筆電連在同一個 Wi-Fi 嗎？
* **答**：**不需要！** 本系統採用 Firebase 雲端穿透架構。手機即便使用自身的 4G/5G 行動網路或任何現場訪客 Wi-Fi，只要直接使用相機掃描主控台的 QR Code，就能以極低延遲（<50ms）跨網穿透控制，徹底告別 AP 隔離困擾！

#### Q2：手抄稿字體大小怎麼調整？
* **答**：在主控台「延伸螢幕」卡片中，直接左右滑動「`A- 至 A+`」字級平滑拉桿，即可在 10px ~ 22px 範圍內無級縮放放映端文字大小。

#### Q3：大螢幕手抄稿與主控台是什麼色彩風格？
* **答**：本系統**全面採用「奢華曜石護眼深色主題」**。主控台為黑曜底金色按鍵，放映端手抄稿開箱即為玄木深色護眼底色，有效降低大投影幕對學員眼睛的強光眩光，營造沈浸清淨的研討氛圍。

#### Q4：防毒軟體彈出安全提示怎麼辦？
* **答**：本專案為開源純腳本架構，批次檔（.bat）僅調用系統標準指令拉起瀏覽器與本地伺服器，絕無任何惡意代碼。若 Windows Defender 提示「已保護您的電腦」，請點選**「其他資訊」➔「仍要執行」**即可。
