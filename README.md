## 🌟 為什麼需要 AMRTF-Desk？

過去在研討班主持廣論、廣海明月手抄稿研討時，主持人與幹部往往面臨諸多痛點：
* ❌ **切換手忙腳亂**：在大螢幕上翻找講次、拉動拉桿，台下學員看著滑鼠游標在投影幕晃動，破壞現場莊嚴氣氛。
* ❌ **現場 Wi-Fi AP 隔離**：教室網路常禁止設備互聯，手機常常連不上筆電，無法走動導播。
* ❌ **播稿滾動難以掌控**：字體放大了卻容易擋住、字級按了反而縮回最小、手動滾輪一滾又跑過頭。
* ❌ **剛才一句沒聽清**：想倒帶卻只能粗暴倒退 10 秒或手動拉進度條，常常把上一句話或這句話腰斬，聽不清楚。
* ❌ **引文與前行影片繁瑣**：切換前行、密集嘛、迴向影片時，YouTube 介面跳出紅條、廣告或相關推薦影片，干擾研討沈浸感。

**AMRTF-Desk（大慈恩研討智能導播系統）** 徹底解決了這一切！

## 📦 第一次安裝與使用（30 秒極簡 3 步驟）

本系統為 **100% 綠色免安裝軟體**，無須複雜驅動、不改動系統登錄檔：

```mermaid
graph LR
    A["1. 下載並解壓縮 ZIP"] --> B["2. 雙擊『建立桌面捷徑.bat』"]
    B --> C["3. 雙擊桌面圖示開箱使用！"]
```

### 步驟 1：下載並解壓縮
* 前往 GitHub **[Releases](https://github.com/ytrt6545ytrt6545/amrtf-desk/releases)** 下載最新版綠色便攜壓縮包（例如 `AMRTF-Desk-v1.2.0-Portable.zip`）。
* 解壓縮至電腦任意慣用目錄（建議解壓縮至 `D:\AMRTF-Desk` 或桌面，路徑盡量避免特殊符號）。

### 步驟 2：一鍵建立桌面捷徑
* 打開解壓縮後的資料夾，找到並雙擊執行：**`建立桌面捷徑.bat`**。
* 系統將自動抓取當前資料夾的真實絕對路徑，在 Windows 桌面上自動產生**「大慈恩研討播控艙」**正式專屬曜金圖示捷徑。

### 步驟 3：開箱日常使用
* 日後每次研討時，直接在桌面雙擊**「大慈恩研討播控艙」**圖示即可一鍵啟動！
* 系統將自動拉起兩個視窗：
  1. 🖥️ **現場放映艙**：自動獨佔第二螢幕/投影機，台下學員看見的是純淨的大字手抄稿與影片。
  2. 🎛️ **講師主控操作艙**：留在筆電螢幕，供主持人從容點擊操作。

> 💡 **如果您已經安裝過舊版？**  
> 完全可以再次執行！新版直接解壓縮覆蓋原資料夾，或解壓至新目錄後雙擊 `建立桌面捷徑.bat`，系統會自動將桌面捷徑導向最新版本，舊設定與快取完全相容。

## 🗑️ 如何解除安裝？（100% 綠色零殘留）

因為 AMRTF-Desk 是標準的綠色免安裝設計：
1. **刪除捷徑**：在 Windows 桌面上，對「大慈恩研討播控艙」圖示按右鍵 ➔ **刪除**。
2. **刪除資料夾**：直接將當初解壓縮的「AMRTF-Desk」整個資料夾刪除進資源回收筒。
3. **完成！** 電腦完全恢復原狀，乾淨無比、絕不殘留任何系統垃圾。

### 1. 🎛️ 講師主控操作艙（講桌／導播席）
高對比、0 贅字、純按鈕與指示燈設計，所有功能皆可一鍵必殺：
![主控台操作艙](docs/images/desk-overview.png)

#### 核心重點功能：
* **🎵 音訊進度條滑動拖曳尋軌 (Scrubbing)**：主控台頂部進度條即時滑動拖曳，雙向微秒級同步跳轉放映端，時間碼即時聯動。
* **🌗 放映端深淺色雙聯切換**：獨立控制外接大螢幕主題：
  - `淺色`：大慈恩原汁原味宣紙雅白（適合白天或明亮研討教室）。
  - `深色`：曜石玄木夜間護眼暗黑（適合關燈或高對比投影幕環境）。
* **📜 手抄稿滾動模式三聯鍵**：
  - `手動`：完全由操作員手動翻閱，音檔播放時不強行位移，同修可安心細看上下文。
  - `持續`：音檔播放時手抄稿自動跟進、逐字自然平滑滾動。
  - `區段`：鎖定在當前研討段落起訖區間內滾動。
* **🛑 法會專用影片獨立停止鍵與互斥急煞**：
  - `🎬 前行`（三稱聖號/開經偈/皈依發心）、`🎬 密集嘛`、`🎬 迴向` 1080p 本地離線秒播。
  - 新增獨立 **`🛑 停止`** 按鍵，可隨時一擊急煞中斷影片並無縫退回手抄稿。
  - 音檔與法會影片互斥機制，絕不發生聲音混雜重疊。
* **🔊 方案 A 懸停音量控制**：滑鼠懸停即可調出音量滑桿，單手滾輪或滑動即可微調放映端輸出音量。
* **起訖區間研討急煞**：下拉選定起點與訖點，播到訖點前 0.25 秒微靜音處自動煞停定格，畫面紋絲不動！
* **語意連貫微復讀**：剛才沒聽清？一按立即智能倒帶回「前三句起點」，字句 100% 完整不被腰斬。
* **師父開示引文 A-B 循環**：智能偵測師父講話時間範圍，師父講完、老師開口前俐落倒帶，絕不洩漏老師聲音。

### 系統設計四大鐵律
1. **信令合約全鏈路閉環**：前端 54 種動作與後端/放映艙 83 個處理端點差集嚴格為 0，杜絕任何幽靈指令。
2. **消滅 Mock 假象 · Live Reality E2E 四重硬鎖**：
   - Win32 HWND 實體視窗存在性（`MainWindowHandle !== 0`）；
   - CDP 視窗外觀幾何渲染（`outerWidth > 0`）；
   - DOM 樣式實質突變斷言（$\Delta \neq 0$）；
   - 真機渲染像素快照存證。
3. **下課關機即焚 (Zero-Garbage)**：不固化房間，每次啟動全新隨機 Token，伺服器關閉時優先抹除雲端資料，無任何歷史垃圾遺留。
4. **單一合法裁判標準**：全域標準測試 `npm test` 涵蓋 4 大套件、**48 項物理測試 100% 全綠 PASS（Exit Code: 0）**。

## 🎯 現場雙螢幕操作指引 (Dual-Screen Setup)

在教室進行研討時，強烈建議搭配投影機或外接大螢幕：

1. **接上投影機或外接電視牆**：將 HDMI 線接上筆電。
2. **切換為延伸螢幕模式**：
   - 按下鍵盤快捷鍵：**`Win + P`**
   - 選擇 **「延伸 (Extend)」**。
3. **分配視窗**：
   - **放映端視窗**：拖曳至外接投影幕，按下右上角或按 `F11` 進入全螢幕放映。
   - **主控台視窗**：保留在筆電螢幕，供主持人從容點擊操作。

## 📖 核心操作技巧一覽

### 1. 極速更換研討講次
- 在主控台點擊右上角「`# 566`」或左側數字鍵盤。
- 輸入講次號碼（例如輸入 `3` 或 `504`），按確認後，放映端將在 1 秒內自動載入對應手抄稿與音檔！

### 2. 音訊進度條滑動拖曳 (Scrubbing)
- 滑鼠直接在頂部進度條上按住並左右拖曳，即可即時預覽時間碼並精準跳轉。

### 3. 手抄稿段落播映 (起訖選單)
- **起點選單**：選擇研討想開始的段落（例如 `05:13 第 4 段`）。
- **訖點選單**：選擇研討想結束的段落（系統自動智慧防呆，訖點絕不會早於起點）。
- 點擊 **`▶ 播放區間`**：音檔將精準播到訖點前 0.25 秒微靜音處俐落急煞，畫面定格紋絲不動。
- 點擊 **`🔁 循環區間`**：播到訖點後自動倒回起點重播，非常適合逐段深入研討。

### 4. 微復讀與師父引文
- **`🔁 微復讀`**：同修聽不清楚剛才這幾句時，按此鍵立即倒帶回前三句開頭，字詞完好連貫。
- **`# 師父引文`**：手抄稿中若有引述師父開示音檔，點擊直接跳至引文起點；再按一次跳至下一段引文。
- **`🔁 引文循環`**：師父引文播放完畢時俐落折返，不洩漏老師後續話語。

### 5. 專用影音秒播與獨立急煞
- **`🎬 前行`**：三稱本師聖號、開經偈、大乘皈依發心（1080p 秒播）。
- **`🎬 密集嘛`**：宗喀巴大師祈請文經典版官方 MV。
- **`🎬 迴向`**：真如老師恭誦大迴向。
- **`🛑 停止`**：影片播放中隨時點擊，立即急煞停止並自動退回手抄稿。

## ❓ 常見問題排解 (FAQ)

#### Q1：手機掃碼需要跟筆電連在同一個 Wi-Fi 嗎？
* **答**：**不需要！** 本系統已升級為 Firebase 雲端穿透架構。手機即便使用自身的 4G/5G 行動網路或任何現場訪客 Wi-Fi，只要直接使用相機掃描主控台的 QR Code，就能以極低延遲（<50ms）跨網穿透控制，徹底告別 AP 隔離困擾！

#### Q2：手抄稿字體大小怎麼調整？
* **答**：在主控台點擊「`🔤 16px`」字級按鈕，即可在官方原生推薦檔位 `13px ➔ 16px ➔ 19px ➔ 22px` 之間循環切換；亦可按旁邊的 `[ + ]` 與 `[ - ]` 進行微調。

#### Q3：大螢幕手抄稿想要黑底護眼，怎麼切換？
* **答**：在主控台直接點擊「放映端主題」的「深色」按鈕，外接投影幕即刻切換為曜石玄木夜間暗黑風格；點擊「淺色」即刻切換回大慈恩宣紙雅白。

#### Q4：防毒軟體彈出安全提示怎麼辦？
* **答**：本專案為開源純腳本架構，批次檔（.bat）僅調用系統標準指令拉起瀏覽器與本地伺服器，絕無任何惡意代碼。若 Windows Defender 提示「已保護您的電腦」，請點選**「其他資訊」➔「仍要執行」**即可。
