# AMRTF-Desk (大慈恩研討智能導播系統)

廣播級大慈恩手抄稿研討智能導播系統，提供現場大螢幕放映端與操作員主控艙的雙向微秒級同步控制。

---

## 🚀 快速啟動

雙擊專案目錄下的啟動腳本：
```bash
啟動大慈恩研討艙.bat
```
或手動啟動：
```bash
node server.mjs
```

### 服務網址
* **🖥️ 現場放映端（電視牆／投影機）：** `http://localhost:8899/?lesson=0566`
* **📱 主控台操作艙（講桌／導播座）：** `http://localhost:8899/desk.html`
* **📶 行動端無線遙控：** 操作艙首頁自動生成區域網路 IPv4 QR Code，手機掃碼即連。

---

## 🌟 核心功能亮點

1. **講次 4 碼智能補零：** 輸入 `1` 或 `20` 自動格式化為 `0001` 或 `0020`，自動探測最新講次並持久化進度。
2. **手抄稿段落區段播映（起訖雙選單）：** 23 個官方標準段落選單，單向防死鎖約束；播至訖點前 0.25s 靜音處 20ms 急煞定格，畫面 100% 紋絲不動、0 雜音。
3. **語意連貫微復讀（前三句＋當前句＋後三句）：** 突破固定滑動窗口，依大慈恩 LRC 字幕鎖定 7 句自然意群，倒帶開播不腰斬。
4. **師父開示引文 A-B 循環：** 智能尾部緊縮（Smart Tail Trimming），在師父講完後、老師開口前俐落倒帶。
5. **本機原生 1080p 零雜訊秒播：** 內建密集嘛、前行、迴向高畫質離線素材，HTTP 206 分段串流秒播；拔除所有 YouTube CC 字幕、標題、頻道頭像與 Logo，播完自動全螢幕回位。
6. **開機自律引擎：** 預設鎖定「🗣️ 播稿 ON」與「📜 持續捲動」，未播放前畫面絕對靜止，按下播放隨音訊同步推進。
