# 專案技術規格書: AMRTF-Desk 廣播級 8 欄磁吸畫布與自訂操作艙系統 (Customizable Deck Canvas)

## 1. 問題陳述 (Problem Statement)
* **當前痛點**：
  1. `AMRTF-Desk` 現行控制台（操作艙）採用固定 HTML 網格佈局，所有按鈕的位置、寬高比例與顯示狀態完全寫死。
  2. 研討會導播高壓現場下，不同操作員（或不同法會環節）對按鈕有截然不同的體感偏好：例如需要將「⏯️ 暫停」、「🔁 段落」與「🔇 靜音」放大為巨型主控鍵以供單手盲操，或將非當前環節之「密集嘛 / 前行 / 迴向」影片彈窗按鈕隱藏避免誤觸。
  3. 原架構缺乏「鎖定模式」與「編輯自訂模式」的防誤觸隔離，若直接支援拖曳將引發高壓現場誤拖、誤放的災難級事故。

---

## 2. 解決方案 (Solution Overview)
本規格書定義一套專為廣播導播現場打造的 **「廣播級 8 欄磁吸畫布系統（Customizable Deck Canvas）」**：
1. **雙模態物理隔離**：預設為「🔒 鎖定作業態（Run Mode）」，點擊 100% 觸發播控；透過右上角按鈕或 `Ctrl + E` 進入「🛠️ 佈局自訂態（Edit Mode）」，頂部泛起琥珀黃呼吸光暈，解鎖拖曳、縮放與隱藏。
2. **8 欄 Stream Deck XL 磁吸網格**：按鈕依據 8 欄等分網格自動磁吸對齊，永不重疊、永不跑版，完美自適應多種螢幕解析度。
3. **按鈕自由三大維度**：
   - **自由移動**：滑鼠拖曳即時避讓並磁吸定位；
   - **自由大小**：右下角拉伸握把 ＋ 點擊快速尺寸選單（支援 $1\times1$、$2\times1$、$2\times2$、$4\times2$），按鈕內容（字體與圖標）採動態階梯式人體工學響應；
   - **自由顯示／隱藏**：點擊右上角 `✕` 即可隱藏；頂部抽屜 Dock 式「📦 未上陣按鈕庫」一鍵優雅召回。
4. **雙層持久化與情境模板**：`localStorage` 秒級即時自動記憶；內建「全功能導播模板」與「研討極簡大鍵模板」；支援 JSON 備份導出/導入與一鍵還原預設。

## 3. 使用者故事與驗收情境 (User Stories & Scenarios)
1. **情境一：日常安全操作（防誤觸）**
   - 作為導播操作員，我希望平常點擊按鈕時按鈕絕不會意外位移或縮小，以確保法會研討播控 100% 穩定無誤。
2. **情境二：進入自訂模式調整介面**
   - 作為操作員，我希望能點擊右上角 `[🛠️ 編輯佈局]` 或按下 `Ctrl + E` 進入自訂模式，頂部顯著亮起琥珀黃光暈，按鈕浮現編輯握把。
3. **情境三：放大關鍵播控鍵**
   - 作為操作員，我希望將「🔁 段落」與「⏯️ 播放」拉大成 $4\times2$ 巨型鍵，按鈕字體自動放大至 28px 且居中高對比，利於現場快速單手盲操。
4. **情境四：隱藏不相關按鈕與頂部召回**
   - 作為操作員，在不播放迴向影片的環節，我希望點擊該影片按鈕右上角 `✕` 將其隱藏；未來需要時打開頂部「📦 按鈕倉庫」點擊即可立即召回畫布。
5. **情境五：模板切換與災難還原**
   - 作為操作員，當佈局調整混亂時，我希望能一鍵點擊 `[↺ 恢復預設]` 瞬間復原；亦能一鍵套用「研討極簡模板（僅 4 顆大鍵）」，或將配置匯出為 `desk-layout.json` 供其他電腦使用。

## 4. 架構與實作決策 (Implementation Decisions)

### 4.1 模組劃分與職責（Deep Modules）
* **`src/desk/modules/deck-canvas.js` (NEW - 畫布引擎深模組)**：
  - 管理 8 欄網格狀態矩陣（佔用、碰撞檢測、磁吸座標計算）；
  - 封裝 Drag & Drop 與 Resize 互動狀態機；
  - 封裝階梯式字體響應演算法（動態計算 `data-size="1x1" | "2x1" | "4x2"` 樣式 class）；
  - 對外僅暴露簡潔公共接口：`initCanvas()`, `enterEditMode()`, `exitEditMode()`, `applyLayout()`, `exportLayout()`。
* **`src/desk/modules/deck-storage.js` (NEW - 持久化與模板管理深模組)**：
  - 封裝 `localStorage` 讀寫與結構驗證；
  - 內建兩套官方預設模板（`DEFAULT_FULL_LAYOUT`、`MINIMAL_FOCUS_LAYOUT`）；
  - 處理 JSON 檔案匯出、匯入校驗與安全降級回退（Fallback）。
* **`src/desk/index.html` & `src/desk/desk.css` (MODIFY)**：
  - 頂部導航列注入 `[🛠️ 編輯佈局]` 開關與「📦 未上陣倉庫（Drawer）」DOM 容器；
  - 主操作區升級為 `.deck-grid-8` 磁吸網格容器；
  - 注入 `.mode-editing` 琥珀黃光暈與邊界指示線樣式，注入實體按鈕尺寸階梯樣式（`.btn-sz-1x1`, `.btn-sz-2x1`, `.btn-sz-4x2` 等）。
* **`src/desk/desk.js` (MODIFY)**：
  - 將原先固定的按鈕點擊綁定解耦，掛載於 `deck-canvas` 容器事件委派中，確保自訂態下阻斷點擊、作業態下高效直通。

### 4.3 狀態機與生命週期 (State Machine)
```
[🔒 RUN MODE (作業態)]  <--- Esc / 點擊完成 / 存檔 ---+
      │                                                │
 點擊編輯 / Ctrl+E                                     │
      ▼                                                │
[🛠️ EDIT MODE (自訂態)] ------------------------------+
  ├── 琥珀黃光暈與外框浮現
  ├── 按鈕點擊鎖定 (preventDefault)
  ├── 啟用 Drag-Handle & Resize-Corner
  ├── 滑出頂部「📦 未上陣倉庫」
  └── 自動儲存變更至 localStorage
```

### 4.4 邊界條件與例外防護
1. **碰撞與邊界越界**：拖曳或拉伸超過 8 欄邊界時，自動限制在邊界內，不可產生負座標或橫向溢出捲軸。
2. **所有按鈕全被隱藏的極端情況**：若操作員將所有按鈕隱藏，畫布顯示醒目提示文字「畫布為空，請從上方倉庫點擊召回按鈕」，並常駐 `[↺ 恢復預設]` 按鈕。
3. **JSON 匯入損毀防護**：匯入外部 JSON 時進行 Schema 檢查，缺少關鍵欄位或格式錯誤時拒絕覆蓋，並彈出防護警告，降級回既有安全配置。

## 5. 測試策略與驗證接縫 (Testing Strategy)
* **測試接縫 (Test Seams)**：
  1. `deckStorage.validate(json)`：單元測試驗證 Schema 正確性與損毀資料降級機制。
  2. `deckCanvas.getLayout()` / `deckCanvas.setLayout(layout)`：行為測試驗證網格座標計算與佔用矩陣。
  3. `deckCanvas.setMode('edit' | 'run')`：驗證事件阻斷接縫，確保作業態下點擊正常觸發、編輯態下點擊不觸發播控。
* **驗收標準 (Acceptance Criteria)**：
  - [ ] 雙擊 `AMRTF-Desk.bat` 啟動後，右上角正確出現 `[🛠️ 編輯佈局]`。
  - [ ] 點擊 `[🛠️ 編輯佈局]` 或按下 `Ctrl + E`，頂部泛起琥珀黃呼吸光暈，進入自訂態。
  - [ ] 按住按鈕可自由拖曳至其他格位，放開滑鼠自動磁吸對齊。
  - [ ] 拖拉右下角握柄或點擊快速尺寸選單，按鈕可在 $1\times1$ 與 $4\times2$ 間平滑切換，大鍵字體與圖標自動等比放大。
  - [ ] 點擊右上角 `✕` 按鈕隱藏至頂部倉庫；點擊倉庫標籤立即召回網格。
  - [ ] 重新整理頁面或重新啟動程式，自訂排版 100% 保持；點擊 `[↺ 恢復預設]` 能瞬間還原官方排版。
