## 1. 系統概述與安裝準備

**AMRTF-Desk** 是專門為大慈恩手抄稿研討（如廣海明月、菩提道次第廣論相關講次）打造的智能播控軟體。
它把傳統「只有一個網頁瀏覽器、滑鼠到處亂晃」的尷尬模式，升級為廣播電視台級別的**「放映端」與「主控台」雙向解耦聯動**架構。

### 軟硬體環境需求
- **作業系統**：Windows 10 或 Windows 11（64 位元）
- **記憶體**：建議 4GB 以上
- **螢幕配置**：單筆電螢幕可操作；**強烈建議搭配投影機或外接螢幕（雙螢幕延伸模式）**。
- **瀏覽器**：Google Chrome 或 Microsoft Edge（系統自帶即可）。

## 2. 快速入門：解壓縮與雙擊啟動

本程式為**完全免安裝綠色版**，下載的是 ZIP 壓縮檔案：

1. **取得壓縮包**：下載 `AMRTF-Desk-v1.0.0.zip`。
2. **解壓縮**：
   - 在 ZIP 檔案上點擊右鍵 ➔ 選擇**「解壓縮全部」**。
   - 將解壓後的資料夾放置在硬碟（例如 `D:\AMRTF-Desk` 或桌面）。
   - ⚠️ **重要**：請勿直接在 ZIP 預覽視窗內執行！一定要完整解壓出來。
3. **啟動軟體**：
   - 進入資料夾，找到 **`啟動大慈恩研討艙.bat`**，**連按兩下滑鼠左鍵**即可啟動。
   - 系統會自動為您拉起主控台與大慈恩手抄稿放映視窗。
4. **建立桌面捷徑（建議）**：
   - 雙擊資料夾內的 **`建立桌面捷徑.bat`**，桌面上會自動出現名為「大慈恩研討智能導播艙」的專屬捷徑，日後直接從桌面雙擊即可開啟。

## 3. 現場設備與雙螢幕配置 (推薦)

為了達到「台下學員只看莊嚴手抄稿，講師在筆電專心操作」的最高品質體驗，請按以下步驟設定雙螢幕：

```text
[ 講師筆電螢幕 ]                        [ 教室投影機 / 電視牆 ]
┌──────────────────────────┐            ┌──────────────────────────┐
│  📱 主控操作艙           │            │  🖥️ 大慈恩手抄稿放映艙   │
│  (按鈕、講次、起訖選單) │    HDMI    │  (純文字、逐字高亮、大字) │
│  講師專用，台下看不見   │ ─────────> │  台下同修專注觀看       │
└──────────────────────────┘            └──────────────────────────┘
```

1. 用 HDMI 線或無線投影將筆電連接至教室投影機。
2. 在筆電鍵盤上同時按下 **`Windows 鍵` + `P`**。
3. 在畫面右側彈出的投影選單中，選擇 **「延伸 (Extend)」**（請勿選「複製」）。
4. 啟動本程式後，將**「放映端手抄稿視窗」**用滑鼠拖動到投影幕上，並按下 **`F11`** 或點選全螢幕按鈕。
5. 將**「主控台操作艙視窗」**留在筆電螢幕上。

## 4. 主控操作艙介面全解析

主控操作艙採用純符號、大按鈕與高對比狀態指示燈設計：

| 按鈕 / 區塊 | 顯示名稱 | 功能說明 |
| :--- | :--- | :--- |
| **講次按鈕** | `# 0566` / 數字鍵 | 顯示當前研討講次，點擊可輸入 1~4 位數講次（如 3 或 504）秒速切換。 |
| **起點選單** | `起: 00:00 (起點)` | 選擇段落研討的開始時間，下拉清單已收斂為黃金大段落。 |
| **訖點選單** | `訖: 05:13 (第4段)`| 選擇段落研討的結束時間，自動智慧約束（訖點絕不會早於起點）。 |
| **播放區間** | `▶ 播放區間` | 精準播放所選起訖區間，到達訖點前 0.25 秒微靜音處自動定格急煞。 |
| **循環區間** | `🔁 循環區間` | 播放到訖點後自動俐落倒回起點重播，適合深入推敲研討。 |
| **微復讀** | `🔁 微復讀` | 自動倒帶至「前三句開頭」，意群連貫完整，不腰斬句子。 |
| **師父引文** | `# 師父引文` | 一鍵直達當前或下一段師父開示音檔起點。 |
| **引文循環** | `🔁 引文循環` | 師父講完後、老師開口前自動俐落倒帶，不洩漏老師聲音。 |
| **前行影片** | `🎬 前行` | 一鍵秒播三稱本師聖號、開經偈與大乘皈依發心（本機 1080p 原生秒播）。 |
| **密集嘛** | `🎬 密集嘛` | 一鍵秒播宗喀巴大師祈請文經典版官方 MV。 |
| **迴向影片** | `🎬 迴向` | 一鍵秒播真如老師恭誦大迴向。 |
| **字級控制** | `🔤 16px` | 官方原生規格循環切換（13px ➔ 16px ➔ 19px ➔ 22px），附 `+`/`-` 微調。 |
| **播稿模式** | `🗣️ 播稿` | 大慈恩原廠逐字高亮與自動捲動開關（深色為 ON，淺色為 OFF）。 |
| **手機遙控** | `QR` | 彈出本機區域網路專屬 QR Code，供手機掃碼無線遙控。 |
| **設定按鈕** | `⚙️ 設定` | 打開系統設定艙，查看 3 支影片離線狀態與一鍵下載工具。 |

## 5. 四大核心研討場景操作指南

### 場景一：開場前行與密集嘛播放
1. 研討開始前，點擊主控台 **`🎬 前行`**。
2. 投影幕會自動瞬間切入純黑全螢幕，播放 1080p 高畫質三稱聖號與開經偈，無任何 YouTube 廣告或紅條。
3. 播完後畫面自動無縫退回手抄稿，接著點擊 **`🎬 密集嘛`** 恭誦大師祈請文。
4. 研討圓滿時，點擊 **`🎬 迴向`** 進行大迴向。

### 場景二：快速跳轉與更換講次
1. 點擊主控台數字鍵盤或講次顯示鈕。
2. 輸入講次（如今日研討第 566 講，直接輸入 `566`，系統自動轉為 `0566`）。
3. 點擊確定，放映端手抄稿與官方音訊秒速載入就緒。

### 場景三：手抄稿逐段研討（起訖區間急煞）
1. 在「起」選單選擇要研討的段落開頭。
2. 在「訖」選單選擇預計研討的段落結尾。
3. 點擊 **`▶ 播放區間`**。
4. 音檔播放至該段末尾時，系統會在聲音結束瞬間**微秒級煞停**，文字定格紋絲不動，不會吃到下一段的聲音，主持人可立即從容帶領大家討論！

### 場景四：沒聽清時的「微復讀」與「師父引文循環」
1. 老師剛剛開示的這幾句話深奧，大家想再聽一次：
   - 點擊 **`🔁 微復讀`**，播放器會精準倒帶至**前三句的起點**，字詞完好無缺重播。
2. 討論到師父引文時：
   - 點擊 **`# 師父引文`**，直接定位到師父開示音檔。
   - 點擊 **`🔁 引文循環`**，師父開示結束時自動折返，專注聆聽師父法音。

## 6. 手機無線遙控 (走動導播)

當主持人想離開講桌、走到台下與同修互動時，可以使用手機隨身遙控：

1. 確認手機連線在教室的**同一個 Wi-Fi 網路**（或手機開熱點給筆電）。
2. 在筆電主控台點擊右上角 **`QR`** 按鈕。
3. 螢幕會彈出清晰的 QR Code。
4. 拿起手機打開相機或 LINE 掃描，點擊開啟網頁。
5. 手機上即刻呈現水晶質感遙控器，邊走動邊按暫停、播放或倒帶！

## 7. 常見問題排解與現場救急

| 狀況描述 | 排查方向與解決方法 |
| :--- | :--- |
| **雙擊批次檔後沒有反應？** | 請確認檔案已完全解壓，不要在 ZIP 預覽內點擊；確保筆電有安裝 Chrome 或 Edge 瀏覽器。 |
| **點擊影片按鈕出現錯誤？** | 請打開「⚙️ 設定」，檢查 3 支影片是否皆顯示「✅ 已就緒」；若未下載，點擊「⬇️ 一鍵自動下載全部影片到本機」。 |
| **放映端字體想要更大一點？** | 點擊主控台「`🔤 16px`」按鈕循環切換，最大可切換至 `22px`（對應大慈恩官方 484% 巨型字），字字清晰疏朗。 |
| **手抄稿文字被頂部播放列遮住？** | 系統已內建自動安全留白（Safe Padding），手抄稿首行始終維持在播放列下方約 90px 處，絕不吃字。 |
| **手機掃碼後顯示「無法連線」？** | 請檢查手機與筆電是否在同一 Wi-Fi。若研討場地 Wi-Fi 有隔離限制，可改用手機開啟「個人熱點」，筆電連上手機熱點後再掃碼。 |
